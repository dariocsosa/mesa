# Mesa de trabajo JL — accesos cortos

Redirecciones a la web app de Apps Script de la Mesa de trabajo de Juan Londoño Inversionista.
El acceso real exige una cuenta de juanlondonoinversionista.com.

- `/` → home · `/fondo` → tablero del vehículo de inversión · `/admin` → administración
- `/dictar` → ventana de dictado por voz (Web Speech API). Existe fuera de Apps Script porque ahí el micrófono está bloqueado; devuelve el texto a la mesa con postMessage

Código de la app: repo privado `jl`, carpeta `mesa-trabajo/`.
